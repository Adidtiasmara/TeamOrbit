# Wireframes - TeamOrbit

Wireframe interaktif sudah dibuat sebagai HTML mockup di file berikut:

- `mockup.html`
- `style.css`
- `script.js`

Buka `mockup.html` di browser untuk melihat UI secara interaktif.

## Halaman yang ada di mockup

### 1. Login

- Logo TeamOrbit
- Input email dan password
- Tombol masuk
- Link ke register
- Demo credentials

### 2. Register

- Input nama, email, password, konfirmasi password
- Validasi password minimal 8 karakter
- Tombol daftar

### 3. Dashboard Tugas

- Topbar: judul halaman, search, notifikasi, tombol + Tugas baru, avatar user
- Sidebar: workspace, menu Tugas, filter proyek
- Stats card: Total, Belum selesai, Selesai, Jatuh tempo
- Filter chips: Semua, Marketing, Engineering, Design, Admin
- Board view: kolom Belum selesai dan Selesai dengan kartu tugas

### 4. Detail Tugas

- Breadcrumb kembali ke dashboard
- Judul tugas
- Action: Tandai selesai/belum selesai, Edit, Hapus
- Panel properti: Status, Proyek, Tenggat, Dibuat oleh
- Panel deskripsi
- Panel assignee: daftar assignee, form tambah assignee

### 5. Admin Users

- Tabel user dengan kolom Nama, Email, Role, Aksi
- Dropdown ubah role (admin/member)
- Admin tidak bisa mengubah role dirinya sendiri

## Catatan Tambahan

- Mockup sudah responsive: sidebar otomatis menjadi off-canvas di mobile.
- Tersedia toggle role (Member/Admin) dan toggle tema gelap/terang di toolbar mockup.
